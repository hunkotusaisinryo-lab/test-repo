## 各店舗の詳細分析

### なかよし（恵比寿）

**コンセプト**：土鍋炊きごはん × 手作り惣菜 × 日本酒

**繁盛の要因**
| 要因 | 内容 |
|------|------|
| 唯一無二の看板 | 土鍋炊きごはんおかわり無料という他にない体験 |
| 高コスパ | 米価高騰の中でも土鍋炊きご飯食べ放題 |
| 手作りのこだわり | だしから手作り・化学調味料不使用 |
| オペレーション設計 | スマホオーダー導入で回転率と人件費を両立 |
| 月次メニュー変更 | 季節感と再来店動機を継続的に作る |
| 40年の信頼 | 老舗ブランドで初来店のハードルが低い |

**弱み**：肉料理への特化なし・SNS映えの仕掛けが少ない

---

### つむぎ堂（新宿）

**コンセプト**：ワンランク上の大衆酒場

**繁盛の要因**
| 要因 | 内容 |
|------|------|
| 3大名物の明確化 | 茹でタン・肉汁鶏・呑める餃子で口コミ拡散 |
| 価格帯の絶妙さ | 大衆酒場より少し上・高級店より安い「ちょうどいい」帯 |
| 個室完備 | 宴会・記念日需要を取り込み客単価UP |
| 若手オーナーのストーリー | 23歳起業がSNSで話題・共感を呼ぶ |
| 飲み放題の充実 | 70種以上・生ビール対応でグループ需要 |

**弱み**：ランチ営業なし・健康軸がない

---

### びゃく（学芸大学）

**コンセプト**：体にやさしい野菜・魚の大人の隠れ家酒場

**繁盛の要因**
| 要因 | 内容 |
|------|------|
| 産地直送の差別化 | 秋田県産野菜の直送という唯一のストーリー |
| 健康軸の明確化 | 「重くない・罪悪感なし」で20〜30代女性に刺さる |
| ドリンクの質 | ナチュールワイン・銘酒日本酒でドリンク単価UP |
| 感度の高いエリア選定 | 学芸大学のリピーター文化にマッチ |
| 従業員教育システム | 複数店舗を行き来する教育で品質を均一化 |

**弱み**：肉料理への特化なし・男性客の来店動機が弱い

---

### ひまり堂（恵比寿）

**コンセプト**：全世代に愛されるネオ大衆酒場

**繁盛の要因**
| 要因 | 内容 |
|------|------|
| 65品のバランスメニュー | 幅広い客層に対応・毎回注文数で見直し |
| SNS映えメニューの設計 | 明太子レアフライ等カラフルで写真映えする商品 |
| 手頃な価格帯 | ドリンク500円・料理ほぼ1,000円未満・客単価3,800円 |
| LINK STYLEのノウハウ | つむぎ堂・ヒロキ倶楽部の繁盛ノウハウを移植 |
| 3大名物の設定 | 和牛ユッケ・おでん・ポテサラで口コミ起点を作る |
| データ管理 | 毎日注文数・売上をスタッフと共有しメニュー改善 |

**初月850万円**の好スタート。月商1,000万円超えを目標。

---

### ひまり商店（新橋）

**コンセプト**：使い勝手のいい居酒屋（海鮮×日本酒×SNS）

**繁盛の要因**
| 要因 | 内容 |
|------|------|
| SNS設計の徹底 | 撮影ポイントを意図的に複数設置、日本酒ボトルを卓上に置くなど |
| インフルエンサー戦略 | メガ〜マイクロインフルエンサーを無料招待・動画投稿で拡散 |
| 低価格で高満足 | 生牡蠣200円仕入れ→429円提供・原価率32%前後 |
| 多様な利用シーン | デート・接待・宴会すべて対応できる設計 |
| 立地の強さ | 新橋駅徒歩4分・ビジネス層の夜需要が厚い |
| オーナーのSNS発信 | X（旧Twitter）で日次売上を公開・注目度UP |

**初月1,700万円**という驚異的なスタート。

## 5店舗に共通する繁盛の法則

| 法則 | 内容 |
|------|------|
| **①3大名物の設定** | 口コミの起点になる「これを食べに来る」商品を必ず持つ |
| **②SNS映えの意図的設計** | 偶然ではなく、撮られることを前提にした商品・空間づくり |
| **③価格帯の絶妙さ** | 高すぎず・安すぎない「ちょうどいい」客単価帯 |
| **④明確なターゲット** | 誰にでも売ろうとせず、ターゲットを絞って刺さる設計 |
| **⑤数値管理と改善** | 感覚ではなく、日次・週次でデータを見てメニュー改善 |
| **⑥来店動機の複数化** | ランチ・ディナー・宴会・デートなど複数の来店シーンを持つ |

## 肉酒場 然との差別化ポジション

```
              健康・発酵軸
                   ↑
             びゃく│
                   │        ★然（ここが空いている）
大衆・気軽 ─────────┼──────────── 上質・こだわり
                   │ なかよし
  つむぎ堂          │
  ひまり堂          │
  ひまり商店        │
                   ↓
               肉・酒場軸
```

**「健康・発酵 × 肉 × 定食居酒屋」のポジションは5店舗いずれも占めていない。**

## 然が取り入れるべき繁盛要素

| 繁盛法則 | 然での実装 |
|---------|-----------|
| 3大名物 | 糀漬けサガリ・豚カツ・鶏ロースト（設計済み） |
| SNS映え設計 | 石板の煙・音・断面のロゼ色・発酵ドリンクの色彩 |
| 価格帯 | ランチ1,800〜2,200円・ディナー3,800〜5,000円 |
| ターゲット | 20〜40代・健康意識の高い男女 |
| 数値管理 | 日次で客数・客単価・注文数を管理 |
| 来店動機 | ランチ定食（日常）× ディナー酒場（目的来店） |
| インフルエンサー | マイクロインフルエンサーの無料招待（ひまり商店モデル） |
