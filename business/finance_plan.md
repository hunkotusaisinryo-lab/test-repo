_作成日：2026-06-05_

## 資金調達プラン

### ステップ①：資本金設計（株比率90:10）

| 株主 | 出資額 | 株数 | 比率 |
|------|-------|------|------|
| オーナー | 630万円 | 90株 | 90% |
| 友人 | 70万円 | 10株 | 10% |
| **資本金合計** | **700万円** | **100株** | **100%** |

### ステップ②：友人の残り資金は株主借入金

| 項目 | 内容 |
|------|------|
| 金額 | 1,430万円 |
| 形式 | 金銭消費貸借契約（書面必須） |
| 金利 | 1〜2% |
| 返済 | 安定期以降に業績連動で返済 |
| メリット | 負債扱いのため株比率に影響しない |

### ステップ③：日本政策金融公庫借入

| 項目 | 内容 |
|------|------|
| 金額 | 500万円 |
| 金利 | 約2% |
| 返済期間 | 7年 |
| 月返済額 | 約6.4万円 |

## この構造のメリット

| ポイント | 内容 |
|---------|------|
| 経営権 | オーナー90%で完全確保 |
| 友人との関係 | 株主＋債権者として明確化、トラブル防止 |
| 公庫審査 | 資本金700万円＋株主借入は「準資本」として評価される |
| 返済柔軟性 | 友人借入は業績に応じて返済調整しやすい |
| 税務 | 借入金利息は経費計上可能 |
