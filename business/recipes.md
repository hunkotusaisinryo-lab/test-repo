## 商品① 糀漬けサガリの石板焼き定食

### コンセプト
塩糀で漬け込んだ牛サガリを低温調理で均一に火入れし、注文後に強火で表面を仕上げる。
ランチはスライス提供、ディナーは石板で自分で焼くスタイル。

### 素材
| 食材 | 分量（1人前） | 備考 |
|------|-------------|------|
| 牛サガリ | 150g | 筋・余分な脂を除去 |
| 塩糀 | 15g（肉の10%） | 市販品 or 自家製 |
| にんにく | 1かけ | すりおろし |
| ごま油 | 少量 | 香り付け |

### 漬け込みレシピ
1. サガリの筋を除き、150gにカット
2. 塩糀・にんにく・ごま油を混ぜ合わせる
3. サガリ全体に均一に塗り、真空パック or ラップで密封
4. 冷蔵庫で**最低12時間・理想24時間**漬け込む

### 低温調理
- **温度：58℃ / 時間：2時間**
- 仕上がり：ロゼ色・しっとりジューシー
- 調理後は急速冷却して冷蔵保存（翌日まで使用可）

### 仕上げ（ランチ）
1. 鉄板 or フライパンを強火で加熱
2. 油を引かずに表面を**30秒×両面**で焼き色をつける
3. 5mm厚にスライスして盛り付け
4. **提供時間目標：8分以内**

### 仕上げ（ディナー：石板焼きスタイル）
1. 石板を230℃以上に加熱してテーブルへ
2. 低温調理済みサガリをスライスして提供
3. お客自身が好みの焼き加減で焼く体験
4. **提供時間目標：5分以内**

### 盛り付けイメージ
```
【ランチ】
・スライスしたサガリ（5〜6枚）をファン状に並べる
・薬味：白髪ねぎ・ミョウガ・青じそ
・添え：季節の焼き野菜2種・ナムル
・ソース：自家製ポン酢 or 塩糀だれ
・ご飯（土鍋炊き or 麦飯）・味噌汁・漬物

【ディナー】
・スライスサガリを石板の横に並べて提供
・薬味・ソース2種（塩糀だれ / 自家製ポン酢）
・岩塩・胡椒は卓上に常設
```

### SNS映えポイント
- ロゼ色の断面 × 白い塩糀コーティング
- 石板から上がる煙・音
- 薬味の色彩（緑・白・紫）のコントラスト

## 商品② 糀味噌漬け豚ロースの厚切りカツ

### コンセプト
糀味噌に漬け込んだ豚ロースを3cm厚でサクッと揚げる。
断面のピンクと特製糀ソースがSNS映え。ハーフサイズで女性も入りやすい設計。

### 素材
| 食材 | 分量（1人前） | 備考 |
|------|-------------|------|
| 豚ロース | 180g（厚さ3cm） | 脂身付き |
| 糀味噌 | 25g | 白味噌ベースの糀入り |
| みりん | 5ml | |
| 酒 | 5ml | |
| 薄力粉 | 適量 | |
| 卵 | 1個 | |
| パン粉（生） | 適量 | 粗め |
| 揚げ油 | 適量 | 米油推奨 |

### 漬け込みレシピ
1. 豚ロースの筋を切り、厚さ3cmに切り出す
2. 糀味噌・みりん・酒を合わせてタレを作る
3. 豚ロース全体にタレを塗り、ラップで密封
4. 冷蔵庫で**最低8時間・理想16〜24時間**漬け込む
5. 揚げる前に表面の味噌を軽く拭き取る（焦げ防止）

### 揚げレシピ
1. 薄力粉 → 卵 → パン粉の順でまとわせる
2. **160℃で4分**（中まで火を通す）
3. **180℃に上げて1分**（衣をカリッとさせる）
4. 油を切って1〜2分レスト
5. 断面がうっすらピンクの状態が理想

### 盛り付けイメージ
```
【ランチ】
・カツを2〜3切れにカット、断面を正面に向けて立てて盛る
・特製糀ソース（自家製）を横に添える
・キャベツの千切り（糀ドレッシング）
・ご飯・赤だし・漬物
・ソースバリエーション：糀ソース / 山椒塩 / 柚子胡椒マヨ

【ディナー単品】
・カット済みカツをプレート盛り
・ソース3種を小皿で添える（カスタム体験）
・白髪ねぎ・大葉をトッピング
```

### SNS映えポイント
- 断面のピンク色 × 濃いめの衣のコントラスト
- 3種ソースを並べたカラフルな小皿
- 立てて盛り付けた断面カット

### ハーフサイズ設計
- 豚ロース90g・1枚カット提供
- 女性・軽めの食事客向け

### 価格

|--|------|
| ランチ定食（フル） | 1,900円 |
| ランチ定食（ハーフ） | 1,400円 |
| ディナー単品 | 1,600円〜 |

## 商品③ 糀漬けブランド鶏の低温ロースト

### コンセプト
ブランド鶏もも肉を糀で漬け込み低温調理で仕上げ。
しっとりした断面の美しさと甘酒ベース特製ソースで「体にいい」仕立て。

### 素材
| 食材 | 分量（1人前） | 備考 |
|------|-------------|------|
| ブランド鶏もも | 200g | 骨なし、皮付き |
| 塩糀 | 20g（肉の10%） | |
| 生姜 | 5g | すりおろし |
| 甘酒 | 10ml | 仕込み用 |

### 甘酒ソース（特製）
| 食材 | 分量 | 備考 |
|------|------|------|
| 甘酒（米糀） | 50ml | 無加糖 |
| 醤油 | 10ml | |
| みりん | 10ml | |
| 生姜汁 | 5ml | |
| バター | 5g | 仕上げ |

### 漬け込みレシピ
1. 鶏もも肉の余分な脂・筋を除去
2. 塩糀・生姜・甘酒を合わせてタレを作る
3. 鶏全体に塗り込み、真空パック or ラップで密封
4. 冷蔵庫で**最低12時間・理想24時間**漬け込む

### 低温調理
- **温度：65℃ / 時間：1時間30分**
- 仕上がり：皮目パリッと・中しっとり
- 調理後は急速冷却して冷蔵保存

### 仕上げ
1. フライパン（鉄板）を強火で加熱、油少量
2. 皮目を下にして**1分30秒**プレスしながら焼く
3. 裏返して**30秒**
4. レストしてからスライス提供

### 甘酒ソースの作り方
1. 甘酒・醤油・みりん・生姜汁を合わせて中火で加熱
2. とろみが出たらバターを加えて乳化させる
3. 温かい状態で提供

### 盛り付けイメージ
```
【ランチ】
・鶏もも1枚をスライス（4〜5切れ）してプレート盛り
・甘酒ソースをかけて提供
・添え：根菜の糀漬け・季節の温野菜
・ご飯・白味噌汁・漬物

【ディナー単品】
・スキレットで提供（熱々演出）
・甘酒ソースを別添え
・ハーブ（タイム・ローズマリー）で香り付け
・ワイン・日本酒とのペアリングをメニューに明記
```

### SNS映えポイント
- 皮目のパリパリ焼き色 × 断面の白くしっとりした質感
- スキレット提供の映え
- 甘酒ソースのとろっとした質感

### 価格
| | 価格 |
|--|------|
| ランチ定食 | 1,800円 |
| ディナー単品 | 1,500円〜 |

### 看板ドリンク① 甘酒フルーツサワー

**コンセプト**：甘酒の自然な甘みとフルーツの酸味を炭酸で繋ぐ、体にいい大人のサワー

| 素材 | 分量 |
|------|------|
| 甘酒（米糀・無加糖） | 60ml |
| 季節のフルーツシロップ | 20ml |
| 焼酎（麦 or 米） | 30ml |
| 炭酸水 | 90ml |
| 氷 | 適量 |

**作り方**
1. グラスに氷を入れる
2. 甘酒 → フルーツシロップ → 焼酎の順で注ぐ
3. 炭酸水をそっと注いで軽くステア
4. 季節のフルーツをトッピング

**季節展開例**
- 春：いちご / 桃
- 夏：マンゴー / パイナップル
- 秋：巨峰 / 洋梨
- 冬：柚子 / りんご

**価格**：780円
