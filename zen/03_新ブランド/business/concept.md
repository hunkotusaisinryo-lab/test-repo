# だし 然（だし ぜん）ブランドコンセプト

_作成日：2026-06-19_

---

## ブランドコンセプト

**「一杯の出汁が、今日を整える。」**

昆布・かつお・独自ブレンドの黄金出汁を軸に、
昼は「出汁定食」で日常を整え、
夜は「出汁体験」で日本の食文化を世界に伝える。

## 然グループにおける位置づけ

```
【昼】
蕎麦 然       → 立食い・超高回転（1,500円）
だし 然       → 座って整う・中回転（1,800円）

【夜】
肉酒場 然     → 発酵×肉の居酒屋（5,000円）
だし 然       → 出汁体験ダイニング（10,000円）
```

昼夜・日本人・インバウンドの全導線を然グループで完結。

## 出汁の差別化設計

### 黄金出汁（オリジナルブレンド）
- 真昆布（北海道産）＋本枯れ節（鹿児島産）
- 麹で発酵させた「発酵出汁」で肉酒場 然との連携
- 「うちの出汁はここでしか飲めない」を武器にする

## 展開計画

### フェーズ1（Y1〜Y2）：東京直営で実証
- 1号店：浅草・銀座・上野エリア（インバウンド×地元客の両取り）
- 2号店：渋谷・新宿エリア（ランチ需要強い）

### フェーズ2（Y3〜Y4）：関西FC展開開始
- 京都：祇園・四条エリア（インバウンド最高密度）
- 大阪：道頓堀・難波エリア

### フェーズ3（Y5〜Y7）：20店舗達成
- 東京直営5店舗
- 関西FC5店舗
- 地方観光地FC10店舗（札幌・福岡・沖縄・金沢等）

### フェーズ4（Y8〜）：海外展開検討
- アジア（台湾・シンガポール・タイ）
- 「DASHI ZEN」として英語圏へのブランド発信

## インバウンド戦略

- **多言語メニュー**（英・中・韓・仏）
- **出汁ストーリーカード**：素材の産地・仕込み方を1枚で伝える
- **QRコード動画**：出汁の引き方を60秒動画で説明
- **Google Map / TripAdvisor**：外国人レビュー獲得を最優先
- **インフルエンサー招待**：開業前に海外グルメ系インフルエンサーに体験してもらう
