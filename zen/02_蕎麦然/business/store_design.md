## 1. 店舗コンセプト

**「2分で届く、本物。無駄のない蕎麦体験。」**

駅前・オフィス街のスタンディング蕎麦店。  
「早い・安い」の立ち食い文化に、素材と出汁への真摯なこだわりを乗せる。  
小さくても「本物感」が漂う、機能美の空間。

## 4. 内装デザイン指針

### カラーパレット

| 要素 | カラー | 素材イメージ |
|------|--------|------------|
| 壁（主） | 白 / クリーム | 塗装（清潔感優先） |
| 壁（アクセント） | 濃紺（藍色）| タイル または 塗装1面 |
| 床 | グレー | 防滑ビニールタイル（清掃性重視） |
| 天井 | 白 | 塗装（天井高を高く見せる） |
| スタンディング台 | ナチュラルウッド天板 × 黒アイアン脚 | シンプル・清潔 |
| カウンター受け渡し | ステンレス | 厨房と統一感 |

### デザイン原則

- **シンプル・清潔感最優先**（立ち食い蕎麦のオペレーション上、清掃しやすい素材）
- **然グループのアクセントカラー（藍色）を壁1面に採用**
- **装飾は極力排除** / 蕎麦産地マップ・蕎麦粉の麻袋のみディスプレイ
- **視認性の高いデジタルメニューボード** をカウンター上に設置

### ライティング設計

| ゾーン | 照明器具 | 色温度 |
|--------|---------|--------|
| フロア全体 | LEDシーリング（均一明度） | 3500K（料理が美しく見える昼白色） |
| カウンター前 | スポットライト × 2〜3 | 3500K |
| アクセント | 藍色壁面への間接照明 | 2700K |

## 5. 厨房設計

### コンセプト

2分提供を実現する「動線の短さ」が最重要。  
茹で機→盛り付け→受け渡しの動線を最短1.5mに凝縮する。

### 厨房レイアウト（4坪）

```
 ─────────────────────────────────
│  受け渡しカウンター（客席側）   │
│  ──────────────────────────── │
│  [盛り付け台（ステンレス）]     │
│  [薬味・器ストック]             │
│                                  │
│  [茹で機（ガス）] [天ぷらフライヤー]│
│  [出汁温蔵タンク（常時保温）]   │
│  [ガスコンロ2口（汁物）]        │
│                                  │
│  [冷蔵庫1台] [シンク1槽]       │
│  [食器洗浄機（アンダーカウンター）]│
 ─────────────────────────────────
```

### 主要厨房設備

| 設備 | 仕様 | 備考 |
|------|------|------|
| 蕎麦茹で機 | 業務用ガス式（槽大小2槽） | 2分提供の核心設備 |
| 天ぷらフライヤー | 小型業務用（揚げたて提供） | 冷凍揚げ物不使用の宣言 |
| 出汁保温タンク | 20L × 2台（温蔵） | 常時出汁を最適温度で維持 |
| 盛り付け台 | ステンレス × 1.5m | 動線の中心 |
| 冷蔵庫 | 縦型 × 1台（コンパクト）| 10坪のため最小限 |

## 7. オペレーション設計（設計に影響する要素）

| 項目 | 設計への影響 |
|------|------------|
| QR前払いシステム | 入口にQR端末・動線をレジレスで設計 |
| 2分提供保証 | 厨房〜受け渡しの動線を1.5m以内に |
| 2人オペレーション | 厨房内は1名が動き回れる最小化 / もう1名は受け渡し専任 |
| 清掃性 | 床・壁はモップ掛け・水洗いに耐える素材指定 |
| 回転率 | スタンディング台の間隔は600mm以上（窮屈感を排除） |

## 8. FC展開のための標準化

蕎麦 然はFC展開を前提とするため、**内装設計を標準パッケージ化**する。

| 標準化項目 | 内容 |
|-----------|------|
| 施工図面 | FC加盟店に標準図面を提供（改変不可） |
| 指定資材 | タイル・塗料・照明器具を品番指定 |
| 厨房設備 | リース契約で統一機種を導入（品質管理） |
| サイン | 看板・暖簾・メニューボードは本部から支給 |
| 工事業者 | 推奨施工業者リストを提供 |
