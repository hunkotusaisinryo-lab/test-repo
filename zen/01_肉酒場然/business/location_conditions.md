# 物件探し条件シート

## 基本条件

| 項目 | 条件 |
|------|------|
| 坪数 | 15坪以上（理想20〜25坪） |
| 家賃 | 50万円以内（共益費込み） |
| 坪単価目安 | 〜25,000円/坪 |
| 階層 | 路面優先、繁華街・好立地なら2階・地下も許容 |

## 設備条件（重飲食必須項目）

| 項目 | 条件 |
|------|------|
| ガス | 都市ガス、容量十分なもの（プロパン不可） |
| 排気・換気 | 厨房排気ダクト設置済み or 新設可能 |
| 排水 | グリーストラップ設置済み優先 |
| 電気容量 | 60A以上 |
| 給排水 | 厨房・客席ともに対応済み |
| 居抜き | 飲食居抜き優先（厨房設備そのまま使えるもの） |

## 立地条件

| 項目 | 条件 |
|------|------|
| 最寄り駅 | 徒歩5分以内 |
| 乗降者数 | 5万人/日以上 |
| 周辺環境 | 夜の人通りがある、飲食店が集まっているエリア |
| 競合 | 同業態（定食居酒屋）が近くに固まっていない |

## 優先エリア

### メイン候補（タイプB：住宅街×SNS集客）
- 三軒茶屋
- 目黒
- 自由が丘

### サブ候補（繁華街・路地裏・居抜き狙い）
- 新宿荒木町・四谷三丁目周辺
- 渋谷桜丘・道玄坂裏
- 恵比寿周辺

## 物件内見時チェックリスト

- [ ] 前テナントが飲食店か（重飲食対応済みの確認）
- [ ] 解約理由が業績不振でないか（立地問題の確認）
- [ ] 昼・夜・週末の人通りを実地確認
- [ ] ガス容量・排気ダクト・グリーストラップの状態確認
- [ ] 電気容量（60A以上）の確認
- [ ] 近隣競合（定食居酒屋）の有無確認
