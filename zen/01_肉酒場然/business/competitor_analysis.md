| 運営会社 | 株式会社四季の台所 |
| 最寄り駅 | 恵比寿駅（JR山手線・東京メトロ日比谷線） |
| 乗降者数 | 約23万人/日（JR12.6万人＋メトロ10.5万人） |
| 創業 | 約40年前 |
| 展開数 | 11店舗（恵比寿・渋谷・目黒・丸の内・水道橋等） |
| 坪数・席数 | 非公開（中規模） |

| 看板商品 | 土鍋炊きごはん・季節の手作り惣菜・地酒 |

**繁盛の要因**

- スマホオーダー導入で回転率・人件費を同時に最適化
- 40年の老舗ブランドによる高い認知と信頼

**弱み**：肉料理への特化なし・SNS映えの仕掛けが弱い・業態拡張性が低い

## 4. 5店舗に共通する繁盛の法則

| 法則 | 内容 | 然での実装 |
|------|------|-----------|
| **① 3大名物の設定** | 口コミの起点になる「これを食べに来る」商品を必ず持つ | 糀漬けサガリ・豚カツ・鶏ロースト（設計済み） |
| **② SNS映えの意図的設計** | 偶然ではなく撮られることを前提にした商品・空間設計 | 石板の煙・音・断面のロゼ色・発酵ドリンクの色彩 |
| **③ 価格帯の絶妙さ** | 高すぎず安すぎない「ちょうどいい」客単価帯 | ランチ1,800〜2,200円・ディナー3,800〜5,000円 |
| **④ 明確なターゲット** | 誰にでも売ろうとせず刺さる設計 | 20〜40代・健康意識の高い男女 |
| **⑤ データ経営** | 感覚ではなく日次・週次でデータを見てメニュー改善 | 日次で客数・客単価・注文数を管理 |
| **⑥ 来店動機の複数化** | ランチ・ディナー・宴会・デートなど複数の来店シーン | ランチ定食（日常）× ディナー酒場（目的来店） |
| **⑦ インフルエンサー戦略** | マイクロインフルエンサーの無料招待でSNS拡散 | 開業前からリスト作成・招待計画（ひまり商店モデル） |

## 5. 市場ポジショニングマップ

```
              健康・発酵軸（高）
                    ↑
              びゃく │
                    │            ★肉酒場 然
                    │         （ここが空白地帯）
  大衆・低価格 ───────┼──────────────── 上質・こだわり
                    │ なかよし
  ひまり堂          │
  ひまり商店        │
  つむぎ堂          │
                    ↓
              健康・発酵軸（低）
```

**結論：「健康・発酵 × 肉 × ランチ＆ディナー両立」のポジションは5店舗いずれも占めていない。**
**肉酒場 然は完全な空白地帯に参入できる。**
