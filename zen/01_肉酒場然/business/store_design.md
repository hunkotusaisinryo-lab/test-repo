# 肉酒場 然 店舗設計仕様書

作成日：2026年6月  
用途：内装設計・施工業者への発注仕様

---

## 1. 店舗コンセプト

**「発酵の香りと肉煙が満ちる、大人の隠れ酒場」**

昭和の居酒屋の温もりと、現代の食へのこだわりが交差する空間。  
街の喧騒を忘れる「非日常感」と、常連が居心地よく過ごせる「日常感」を共存させる。

## 4. 内装デザイン指針

### カラーパレット

| 要素 | カラー | 素材イメージ |
|------|--------|------------|
| 壁（主） | 焦げ茶 / 柿渋色 | 古材風板張り |
| 壁（厨房前） | 黒タイル | 100角マットタイル |
| 床 | ダークブラウン | ラフ削り杉フローリング（焼き加工） |
| 天井 | 黒天井 + 古材梁 | 黒塗装 × 古材（フェイク可） |
| カウンター | ケヤキ無垢 | 厚板60mm・ニス仕上げ |
| テーブル | アイアン × 古材 | スチールフレーム + 古材天板 |
| 椅子 | ブラックフレーム | パイプ椅子風（昭和感）または 古木スツール |

### テクスチャ・素材

- **壁**: 古材風板張り（縦張り）+ 一部 黒壁（漆喰・粗面）
- **床**: 焼き杉フローリング（オイル仕上げ）または モルタル床（ランダムなひび割れ風）
- **厨房前**: 100角黒マットタイル + 網代（あじろ）模様のディテール
- **天井**: 黒塗装梁見せ + 古材細格子 / 鉄製ダクトをあえて見せる
- **照明**: 裸電球・エジソン電球メイン（オレンジ感強め・2400K）

## 5. 厨房設計

### コンセプト

オープンキッチン（カウンター越しに炭火が見える）。  
炭の香り・肉の焼ける音・職人の手仕事が「体験」になる。

### 厨房レイアウト（6坪）

```
 ─────────────────────────────────
│  カウンター（開口部：炭火グリル見せ）│
│  ──────────────────────────── │
│  [炭火グリル 大] [ガスコンロ4口] │
│  [発酵室（小型・扉付き）]         │
│  [肉切り台（大理石）]             │
│                                   │
│  [業務用冷蔵庫2台] [冷凍庫]      │
│  [シンク2槽] [食洗機]            │
│  [酒類ストック棚]                 │
 ─────────────────────────────────
```

### 主要厨房設備

| 設備 | 仕様 | 備考 |
|------|------|------|
| 炭火グリル | 業務用 / 幅90cm以上 | 煙・熱対策の大型換気扇必須 |
| ガスコンロ | 4口（煮物・ソース用） | |
| 発酵室 | 温度・湿度管理可能な小型庫 | 発酵肉・味噌・糀の仕込みに |
| 肉切り台 | 大理石または人工大理石 | 見せる調理台として設計 |
| 換気設備 | 大型フード + 外部排気 | 炭火・肉煙対策（近隣配慮） |
| 冷蔵庫 | 縦型×2台（食材・ドリンク分離） | |

## 7. 音環境・BGM

- **音量**: 賑わい感のある中音量（50〜55dB）
- **BGM方針**: ジャズ・ブルース・昭和歌謡（セレクト次第でムードが決まる）
- **ピーク時**: やや音量を上げて活気を演出
- **深夜帯**: 落ち着いたジャズに切り替え

---

## 8. 換気・消防設計（重要）

| 項目 | 要件 |
|------|------|
| 排気ダクト | 炭火対応の大型フード（幅1.2m以上）|
| 給気設備 | 自然給気 + 機械給気併用 |
| 消火設備 | 厨房用消火設備（グリス火災対応）必須 |
| 消防確認 | 物件確定後に消防署との事前相談必須 |
| 近隣配慮 | 排気口の向き・脱臭フィルター設置 |
